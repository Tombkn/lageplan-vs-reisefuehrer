# Lageplan oder Reiseführer

Handy-Lernzettel: `themen-maphack` gegen `discovery-map-gpt`.

Live: https://tombkn.github.io/lageplan-vs-reisefuehrer/

## Ein Satz

Der Lageplan zeigt, wo etwas steht. Der Reiseführer erklärt und schickt dich in die nächste Stadt.

## Auf dem Handy

1. Die Live-Seite öffnen.
2. iPhone: Safari → Teilen → **Zum Home-Bildschirm**.
3. Android: Chrome → Menü → **App installieren**.

Das ist ein Lernzettel, kein neuer Skill.
